## Reporting a vulnerability

Please report security issues for AgentMesh using https://github.com/agentmesh-oss/agentmesh/security/advisories/new

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x.x   | :white_check_mark: |
| 2.x.x   | :x:                |
| 1.x.x   | :x:                |
