# Hosted Solutions

## Orkes
[Orkes](https://orkes.io) offers a cloud-hosted, enterprise-grade version of AgentMesh, enabling teams to get started with minimal operational overhead. Besides full compatibility with AgentMesh OSS, Orkes AgentMesh provides [additional features](https://www.orkes.io/platform/agentmesh-oss-vs-orkes) not available in the open source release.

Here are the options for using AgentMesh via Orkes:

- Developer Edition
- Cloud Hosting Plans

Orkes also operates a [Discourse](https://community.orkes.io/) forum for the community to discuss and share how to use AgentMesh.

### Developer Edition
The free Orkes Developer Edition for AgentMesh is available at [developer.orkescloud.com](https://developer.orkescloud.com/). The Developer Edition comes with all of Orkes' enterprise features, including a visual workflow editor, AI orchestration suite, event-driven connectors, human-in-the-loop tasks, and more. You can create and execute workflows from the UI or API.

### Cloud Hosted AgentMesh
Orkes provides multiple options of hosted AgentMesh clusters in the cloud (AWS, Azure, and GCP, in addition to private clouds) with enterprise support provided by the Orkes team. Learn more about [Orkes Cloud here](https://orkes.io/cloud).
