# Project

This is a distributed workflow orchestration engine designed for microservices.

## Building and Running

### Prerequisites

- Java 21+

### Build

To build the project, run:

```shell
./gradlew build
```

### Tests

To run the tests:

```shell
./gradlew test
```

### Spotless formatting

To apply code formatting:

```shell
./gradlew spotlessApply
```
